# 📊 Supply Chain Analytics Dashboard — Power BI

## 📌 Project Overview

This project focuses on analyzing supply chain data and transforming raw data into meaningful business insights using **Microsoft Power BI**.

The dashboard provides an interactive view of key performance indicators, sales trends, product performance, and supply chain metrics to support data-driven decision-making.

## 🎯 Project Objectives

* Analyze overall supply chain performance
* Track important business KPIs
* Identify sales and product trends
* Analyze performance across different categories/regions
* Create interactive and user-friendly dashboards
* Convert raw data into actionable business insights

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Modeling**
* **Data Cleaning & Transformation**
* **Data Visualization**

## 🔄 Project Workflow

```text
Raw Data
   ↓
Data Cleaning
   ↓
Power Query Transformation
   ↓
Data Modeling
   ↓
DAX Measures & KPIs
   ↓
Interactive Dashboard
   ↓
Business Insights
```

## 📊 Dashboard Features

* KPI summary
* Sales performance analysis
* Product/category analysis
* Supply chain performance
* Trend analysis
* Interactive filters and slicers
* Business-focused data visualizations
